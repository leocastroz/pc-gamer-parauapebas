# PC Gamer RTX 3080 | Parauapebas, PA

Página de venda de um desktop com RTX 3080 AFOX 10 GB, i5-13400F e 16 GB de memória RGB. O preço anunciado é R$ 7.500,00. Os botões de contato abrem uma conversa no WhatsApp com uma mensagem preenchida.

## Abrir no computador

Extraia o ZIP inteiro e abra `index.html` no navegador. Mantenha `styles.css`, `app.js` e a pasta `assets/` no mesmo local. A página é estática e não exige instalação nem compilação.

## Publicar no GitHub Pages

1. Envie os arquivos extraídos para a raiz de um repositório no GitHub. O arquivo `index.html` deve aparecer na primeira tela do repositório.
2. Abra **Settings → Pages**. Em **Build and deployment → Source**, selecione **Deploy from a branch**.
3. Escolha o branch em que colocou os arquivos, normalmente `main`, selecione **/(root)** e clique em **Save**.
4. Abra a URL exibida em **Settings → Pages** após a publicação.

[Documentação do GitHub Pages](https://docs.github.com/pt/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Arquivos e manutenção

- `index.html` contém o anúncio, o preço, a ficha técnica, os links para WhatsApp e os metadados. Se alterar o preço, atualize também a mensagem de contato, os metadados e a comparação com o levantamento de peças.
- `styles.css` define o layout responsivo, as cores RGB e as animações.
- `app.js` controla a montagem interativa e a ampliação da galeria. O anúncio, os links e as fotos continuam acessíveis com JavaScript desativado.
- `assets/` contém as três fotos reais em WebP e o recorte transparente do gabinete em PNG. O site usa a versão WebP do recorte para reduzir o tamanho do carregamento.

Quando vender o PC, você pode despublicar a página em **Settings → Pages** ou atualizar o texto e a disponibilidade do anúncio.

A comparação de preço usa a estimativa fornecida pelo vendedor em setembro de 2026. Os dados do processador seguem a [ficha técnica da Intel](https://www.intel.com.br/content/www/br/pt/products/sku/230501/intel-core-i513400f-processor-20m-cache-up-to-4-60-ghz/specifications.html).
